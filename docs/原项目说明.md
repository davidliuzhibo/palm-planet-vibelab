# 掌心星球 PalmPlanet

PICO Project Swan 上的全沉浸游戏：一颗小星球悬在面前，种森林、建村庄、开城市，守住气候，最后把火箭送上天。

> 2026-11-05 v0.1（versionCode 1）：
> - 十二关，三章，中间穿插干旱行星和火山这类难局。
> - 看向星球上一块地方捏一下，它转到面前；再按面板上想造的东西。面板上的箭头也能转星球。
> - 二氧化碳和气温按规则计算：森林和海洋吸碳，城市排碳。气温低于 6℃ 或高于 24℃ 就是失控，撑不过 30 秒文明中断。
> - 人口解锁时代：村镇、城市、航天。
> - 星星：完成一星；三星时间内完成再加一星；气候一次没失控再加一星。
> - 铜、银、金奖杯，金奖杯解锁火箭齐射。说明窗口讲温室效应、碳循环、海洋和火山。
> - 调试钩子 AutoPilot（logcat 标签 PlanetTest）。

场景开局只摆一次，之后转头不会移动它。

第一轮真机反馈改了这些：星球从 0.72 米拉远到 1.05 米；说明卡移到星球右侧，再往右拉开一点，星球转动时不会盖住卡片和「开始」按钮。云层的左右接缝也修了。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`。
